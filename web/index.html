OxBuy
Source on GitHub OxDeAI protocol

An agent that pays for APIs, and cannot pay for anything it was not authorized to.

OxBuy buys paid API calls over x402 with USDC on Celo. Before any payment is signed, OxDeAI checks that the exact purchase was authorized: the service, the recipient, the price, the request itself. If anything differs, the wallet key is never even read.

      What is real on this page

      Real

      • The OxDeAI authorization service, payment gateway, executor and journal, in both sections.
      • The x402 client: it reads the seller's 402, compares it with the authorization and signs an EIP-3009 transfer whose nonce is derived from the authorized intent, so one authorization can settle at most once.
      • The live purchase: a USDC payment on Celo Sepolia to the buy gateway, visible on the block explorer.

      Simulated or limited

      • In the playground, the chain, the facilitator and the seller are local simulations.
      • The agent is a script, not a language model. It proposes purchases; OxDeAI decides.
      • This page uses testnet only. Mainnet purchases need an explicit operator opt-in in the command-line tool and are never exposed here.
      • The live path runs the agent, the policy and the wallet key in one server process. The process-isolated deployment is in the repository and is not what this page runs.

      Runs from the command line on 8 November 2026, 0.005 USDC each: Celo mainnet 0x6c7cb96e…fd1b59, Celo Sepolia 0x29bacbec…6ef937.

      OxBuy is a proof of concept built on OxDeAI, an open protocol for deterministic authorization of agent actions.
